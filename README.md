# 📊 Netflix Users Analytics

Projeto de **Análise Descritiva End-to-End** utilizando dados de usuários da Netflix.

O objetivo do projeto é explorar informações sobre os usuários, seus planos de assinatura, preferências, tempo de consumo e receita estimada.

O fluxo do projeto foi desenvolvido utilizando **Python para limpeza e tratamento dos dados**, **MySQL para análise** e **Power BI para a criação de um dashboard interativo**.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- MySQL
- MySQL Workbench
- Power BI
- Git e GitHub

## 🐍 Limpeza e tratamento — Python

Nesta etapa, os dados foram preparados para análise utilizando Python e Pandas.

Principais atividades:

- Verificação de valores nulos;
- Identificação de registros duplicados;
- Validação dos tipos de dados;
- Padronização de informações;
- Tratamento da coluna de datas;
- Validação de possíveis inconsistências.

Após o tratamento, a base foi preparada para as próximas etapas do projeto.

## 🗄️ Análise de dados — MySQL

Os dados tratados foram importados para o MySQL, onde foram realizadas consultas para analisar diferentes informações da base.

Principais análises:

- Distribuição de usuários por país;
- Tipos de assinatura;
- Gêneros favoritos;
- Faixas etárias;
- Tempo médio de consumo;
- Consumo por plano;
- Receita estimada por plano e país.

Para permitir análises financeiras, foram adicionados **valores simulados para cada tipo de assinatura**.

> Os valores utilizados para a receita são fictícios e foram adicionados exclusivamente para fins de estudo e análise.

## 📈 Dashboard — Power BI

Os resultados foram apresentados em um dashboard interativo dividido em três páginas:

### 📊 Visão Geral
Principais KPIs, usuários, assinaturas e receita estimada.

### 👥 Perfil dos Usuários
Informações sobre idade, países, gêneros favoritos e tipos de assinatura.

### 💰 Consumo e Receita
Análise do comportamento de consumo, horas assistidas e receita estimada.

Também foram utilizadas medidas em **DAX** para o cálculo dos principais indicadores.

## 🚀 Fluxo do Projeto

**Python → Limpeza e Tratamento → MySQL → Análise SQL → Power BI → Dashboard**
